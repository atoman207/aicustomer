# database／AI の回答情報源

AI（文字・声・電話の 3 窓口と LINE）は、ここにある情報だけを根拠に回答します。書かれていないことは推測せず、「担当者より折り返し」をご案内します。
AI が読むのは **3 つの JSON ファイル**だけです。ビルドに同梱されるため、Vercel・VPS のどちらでもそのまま動きます。

| ファイル | 内容 | 優先 |
| --- | --- | --- |
| `manual.json` | 一畳屋の顧客対応マニュアル（`顧客対応マニュアル.xlsx` のシート「ＡＩ相談ソース」から変換）。上部の文章（会社情報・営業時間・よくある問い合わせ）10 件と、下部の料金表（畳・襖・障子・網戸・ヘリ・雑工事など）12 表 | 1（最優先） |
| `company.json` | 会社情報と商品知識（一畳屋からご提供いただいた内容を、お客様にそのままお答えできる文章に整えたもの。畳表の耐用年数・価格の違い・おすすめ、新調のタイミング・畳床、ヘリのグレード、防ダニシート、へり無し畳、襖紙・障子紙の違い、戸襖・障子の新調、アミ戸の網の種類と新調 など）。`questions` はお客様の聞き方の例 | 2 |
| `website.json` | 一畳屋ホームページ（ichijoya.co.jp）から学習した内容（会社概要・店舗とスタッフ・畳表や襖紙の特徴 など） | 3 |
| `顧客対応マニュアル.xlsx` | `manual.json` の変換元（AI は直接読みません） | — |
| `manual-rules.json` | Excel を変換するときの規則（社内向けの行の除外、料金表の列名の言い換え、検索語、料金の回答に添える一畳屋の案内 `tableGuides`：「畳の新調は建材床（3型）・処分費込み」「襖の新調は本襖の価格」など） | — |

管理画面の「ナレッジ」で追加した内容は、これらより優先して使われます。

## マニュアルの更新（Excel → JSON）

```bash
npm run knowledge:build   # 顧客対応マニュアル.xlsx → manual.json（中身が同じなら更新しません）
```

1. `顧客対応マニュアル.xlsx` を更新する（ファイル名・シート名「ＡＩ相談ソース」はそのまま）
2. `npm run knowledge:build` を実行（文章・料金表の件数と、除外した社内向けの行が表示されます）
3. `database/` をコミットしてデプロイ（Vercel は push で自動デプロイ）すると、3 窓口の回答に反映されます

- 自由形式のまま変換できます。上部の文章は見出し（前後が空行の短い行）ごとに、下部の料金表は列が並ぶ表ごとに分けて読み取ります。表の配置（左から 畳／襖・障子・網戸／ヘリ無し・置き畳／ヘリ有り）を変えずに数字を書き換えれば、そのまま料金の回答に反映されます。
- **社内向けの書き込み**（「思案中」で始まるメモ、原価・売値の計算式、仕入先名など）は `manual-rules.json` の規則で除外され、`manual.json` には入りません（件数だけを記録）。新しく社内メモを書くときは、行の先頭に「【社内】」と付けると除外されます。
- **Google スプレッドシートを接続した場合**（`GAS_WEBHOOK_URL` など）：`manual.json` の代わりにシートを直接読み、書き換えると約 1 分で 3 窓口に反映されます（管理画面の「マニュアルを再読み込み」で即時）。

## 会社情報（company.json）の照合

各項目の `anchors` に書いた語（営業時間「8:00~17:00」、店舗の番地など）が、現在のマニュアル（`site:` で始まるものはホームページ）に含まれているかを読み込みのたびに確認します。マニュアル側の内容が変わって語が見つからなくなった項目は、古い回答を出さないよう自動的に使われなくなり、管理画面に「要確認」と表示されます（その間はマニュアルの文章から回答します）。

## ホームページの学習

```bash
npm run learn:site      # ichijoya.co.jp を読み直して website.json を作り直す
```

管理画面の「ホームページから再学習」でも同じことができます（OpenAI は使いません）。お知らせ・採用・LINE のページ、Google の口コミは対象外です。マニュアルと食い違う表記（例：襖の「2日仕上げ」、施工件数・職人数の旧表記）は学習しません（`src/lib/site-learn.ts` の `SITE_OVERRIDES`）。

## OpenAI を使うのは必要なときだけ

| 質問の例 | 回答のしかた | OpenAI |
| --- | --- | --- |
| 「朱雀の襖の両面はいくら？」「障子の大サイズは？」「畳の処分費は？」 | 料金表から直接（品名・列・注記を判定） | 使わない |
| 「益城町は来てもらえますか？」「天草市は？」 | マニュアルの営業範囲から直接 | 使わない |
| 「営業時間は？」「土日に工事できる？」「お店に行ってもいい？」 | 会社情報の該当項目をそのまま | 使わない |
| 一度 AI が答えた質問と同じ質問 | 学習済みの回答を再利用（根拠が変わったら使わない） | 使わない |
| ナレッジに答えがない質問（「支払い方法は？」など） | 「担当者より折り返し」を案内し、管理画面の「答えられなかった質問」に記録 | 使わない |
| 上記以外（組み合わせの相談など） | 関係するナレッジ数件だけを渡して AI が回答し、その回答を学習 | 使う（短い指示＋関係する部分だけ） |
