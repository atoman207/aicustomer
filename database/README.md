# database／AI の回答情報源

AI（文字・声・電話の 3 窓口と LINE）は、**一畳屋の Googleスプレッドシート**と**一畳屋のホームページ（ichijoya.co.jp）**の内容だけを根拠に回答します。書かれていないことは推測せず、「担当者より折り返し」をご案内します。

| ファイル | 内容 |
| --- | --- |
| （Googleスプレッドシート） | 回答の正。顧客対応マニュアルのタブ（文章：会社情報・営業時間・営業範囲・よくある問い合わせ・支払方法／料金表：畳・ヘリ・襖・障子・網戸・ヘリ無し半畳・置き畳・ヘリ有り1畳物・雑工事・カーテンレール／料金表の下の商品知識：畳について・襖・障子について・アミ戸について）。サービスアカウントで非公開のまま読み取り、書き換えると約 1 分で 3 窓口に反映 |
| `manual.json` | スプレッドシートの保存版（`npm run knowledge:build` でシートから作成）。シートを読めないとき（Google の障害・共有の解除など）だけ使う |
| `website.json` | ホームページ（ichijoya.co.jp）から学習した内容（会社概要・店舗とスタッフ・畳表や襖紙の特徴 など）。料金がスプレッドシートと違う項目は自動で使わない |
| `manual-rules.json` | シートを読み取るときの規則（社内向けの行の除外、料金表の列名の言い換え、料金表を探す語）。回答の内容そのものは入れない |

## スプレッドシートの接続（最初に 1 回）

1. スプレッドシートの「共有」に、サービスアカウント `ichijoya-sheets-api@ichijoya.iam.gserviceaccount.com` を **編集者** として追加（受付を「受付一覧」タブに記録するため。読むだけなら閲覧者でも可）
2. `.env`（Vercel では Settings › Environment Variables）に次を設定して再起動／再デプロイ
   - `GOOGLE_SERVICE_ACCOUNT_EMAIL`・`GOOGLE_PRIVATE_KEY`（サービスアカウントの鍵。JSON ファイルの `client_email`・`private_key`。鍵のファイルはリポジトリに置かない）
   - `KNOWLEDGE_SHEET_ID`（スプレッドシートの URL の `/d/` と `/edit` の間）・`KNOWLEDGE_SHEET_GID`（回答に使うタブの URL の `#gid=` の数字）
3. 管理画面の「AIの学習状況・情報源」で「接続中」になっていることを確認

## スプレッドシートを更新したとき

- 接続していれば、シートを書き換えると約 1 分（`KNOWLEDGE_CACHE_SECONDS`）で 3 窓口すべての回答に反映されます（管理画面の「スプレッドシートを再読み込み」で即時）。
- 保存版（`manual.json`）も新しくしておくと、シートを読めないときも新しい内容で答えられます：

```bash
npm run knowledge:build   # スプレッドシート → manual.json（中身が同じなら更新しません）
```

- 自由形式のまま読み取れます。上部の文章は見出し（前後が空行の短い行）ごとに、下部の料金表は列が並ぶ表ごとに分けて読み取ります。表の配置を変えずに数字を書き換えれば、そのまま料金の回答・合計の目安の計算に反映されます。
- 料金表の下にある「〇〇について」の見出しのまとまり（畳について など）は、料金表ではなく文章として「・」の項目ごとに読み取ります（`manual-rules.json` の `textSectionTitle`）。
- **社内向けの書き込み**（「思案中」で始まるメモ、原価・売値の計算式、仕入先名など）は `manual-rules.json` の規則で除外され、回答にも `manual.json` にも入りません。新しく社内メモを書くときは、行の先頭に「【社内】」と付けると除外されます。

## ホームページの学習

```bash
npm run learn:site      # ichijoya.co.jp を読み直して website.json を作り直す
```

管理画面の「ホームページから再学習」でも同じことができます（OpenAI は使いません）。お知らせ・採用・LINE のページ、Google の口コミは対象外です。

## OpenAI を使うのは必要なときだけ

| 質問の例 | 回答のしかた | OpenAI |
| --- | --- | --- |
| 「朱雀の襖の両面はいくら？」「6畳の表替えはいくら？」 | スプレッドシートの料金表から直接（数量があれば合計の目安も計算） | 使わない |
| 「益城町は来てもらえますか？」 | スプレッドシートの営業範囲から直接 | 使わない |
| 一度 AI が答えた質問と同じ質問 | 学習済みの回答を再利用（根拠が変わったら使わない） | 使わない |
| スプレッドシート・ホームページに答えがない質問 | 「担当者より折り返し」を案内し、管理画面の「答えられなかった質問」に記録 | 使わない |
| 上記以外（営業時間・工期・組み合わせの相談など） | スプレッドシート・ホームページの関係する部分だけを渡して AI が回答し、その回答を学習 | 使う（短い指示＋関係する部分だけ） |
